# وصّلها v2 — منصة توصيل لكل محافظات مصر (نسخة تجريبية)

## الحسابات التجريبية
- الأدمن: موبايل `admin` / كلمة مرور `admin123`
- سائق: موبايل `01001001001` / كلمة مرور `1234` (القاهرة)
- زبون: سجّل حساب جديد من زرار "دخول"

## المميزات
- محافظات مصر الـ27 + اختيار المحافظة
- أدوار: زبون / سائق / شركة توصيل / أدمن
- لوحة أدمن: إضافة وحذف محلات ومطاعم وصيدليات (ترتيب أبجدي)، إدارة السائقين والشركات، الإعلانات، أرقام طوارئ المحافظات، الطلبات والمستخدمين
- شات بين الزبون والسائق + إشعارات للجميع
- خرائط جوجل (تضمين + زر ملاحة للسائق)
- قسم طوارئ لكل محافظة

## النشر على GitHub Pages
ارفع index.html في ريبو جديد ← Settings ← Pages ← Deploy from branch ← main/(root)
للدومين: ضيف CNAME باسم الساب دومين يشاور لـ YOUR-USERNAME.github.io

## ملاحظة
نسخة تجريبية بدون سيرفر: البيانات تتحفظ في متصفح المستخدم (localStorage).
للإطلاق الحقيقي: Firebase/Supabase + بوابة دفع + Google Maps API key.
